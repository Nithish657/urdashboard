Questions before you start

Do I need prior experience?

No. Every path starts at Ground school and assumes you know nothing. If you already have basics, the path finder skips you ahead.

What if I miss a live class?

Every live class is recorded and added to your recorded classes within a few hours, together with the mentor's notes.

Is the first module really free?

Yes. Try the first module of any course and decide after you have built your first mini project.

What is a skill passport?

A shareable page that lists every skill you have proven, with links to the project, the mentor's feedback and the date.
